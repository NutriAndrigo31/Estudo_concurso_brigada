# Estudo Concurso — Brigada Militar RS (Nutricionista, Fundatec)

Material de estudo completo e interativo para o Processo Seletivo da Brigada Militar do RS (Edital DPF/DRESA nº 01/2026), cargo de 2º Sargento Temporário de Saúde — Nutricionista.

Acesse o material publicado aqui: https://nutriandrigo31.github.io/Estudo_concurso_brigada/

Contém o texto integral, artigo por artigo (com Títulos/Capítulos/Seções indicados), de:

- Lei Complementar nº 10.990/1997 — Estatuto dos Militares Estaduais
- Decreto nº 43.245/2004 — Regulamento Disciplinar
- Lei Complementar nº 10.992/1997 — Carreira dos Militares Estaduais
- Lei nº 15.583/2020 — Programa de Militares Estaduais Temporários (PMET)
- Decreto nº 57.390/2023 — Regulamento de Movimentação
- Trechos relevantes do Edital (fases, requisitos, estrutura da prova, cronograma)

## Recursos

- Busca em tempo real por palavra, artigo ou número
- Cada artigo é expansível individualmente
- Checkbox de "estudado" em cada artigo, com indicador de progresso por capítulo/seção
- Painel de relatório com percentual geral e por norma, e lista do que falta estudar
- Exportar/Importar progresso (para levar entre dispositivos diferentes)

## Como estudar

Acesse o link do GitHub Pages acima em qualquer navegador (celular, tablet ou computador) — não precisa instalar nada.
